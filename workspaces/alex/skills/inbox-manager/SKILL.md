# Personal Inbox Manager

管理用户的个人 Inbox：

1. 判断是否为 Inbox 内容（待办/想法/灵感/计划/提醒）
2. 精简 → 一句准确的话
3. 打标签（🤖 AI学习 / 📚 英语学习 / 🚀 项目 / 🏠 生活 / 💡 灵感，新主题自动新增）
4. 追加到 `~/Documents/ai-assistant/acquisition/inbox.md`，格式：`- 时间 · 标签 · 精简内容`
5. 在 `~/Documents/ai-assistant/acquisition/overview.md` 的「📥 最近记录」区追加链接指向 inbox 条目
6. 简短回复：精简结果 + 标签

## 规则

- 不删除用户输入
- 不遗漏信息
- 不过度总结
- 保持简洁
